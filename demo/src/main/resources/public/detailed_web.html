웹 개발 (기술 스택 및 로드맵)

웹은 크게 화면을 만드는 프론트엔드, 서버와 데이터를 다루는 백엔드, 둘 다 하는 풀스택으로 나뉩니다. 저는 풀스택 로드맵을 보면서 백엔드 쪽으로 깊게 공부하고 있습니다.

해본 것

  • HTML, CSS, JavaScript로 반응형 화면 만들기
  • Java 기초 문법, 스프링 부트 URL 매핑과 컨트롤러
  • Node.js로 웹 서버를 만들고 실제 도메인으로 배포

하고 싶은 기술

  • REST API 설계
  • OAuth 소셜 로그인
  • HTTPS와 인증서
  • WebSocket 실시간 알림
