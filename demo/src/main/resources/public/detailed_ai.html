AI 활용 서비스

AI 모델을 직접 만드는 것보다, 이미 있는 AI 모델 API를 서비스에 연결해서 사람들이 쓸 수 있게 만드는 데 관심이 있습니다.

해본 것

  • AI API로 사용자가 적은 문장의 분위기를 읽고 노래 추천하기 (무드 뮤직)
  • AI가 하루에 쓰는 양(토큰) 한도를 정하고, 같은 질문은 저장해 둔 답으로 대신하기
  • AI가 노래마다 분위기 태그를 달게 해서 플레이리스트 자동 생성

하고 싶은 기술

  • 스프링 부트에서 AI API 호출하기 (Spring AI)
  • 검색 + AI를 합친 RAG
  • AI 답변 품질 평가하기
