웹 보안 기본기

웹 서비스는 만드는 것만큼 안전하게 지키는 것이 중요합니다. 실제 서비스를 운영하면서 보안의 필요성을 느끼고 기본부터 공부하고 있습니다.

해본 것

  • 비밀 키(API 키)를 코드에 넣지 않고 환경 변수 파일로 분리
  • 새 창 링크에 rel="noopener noreferrer" 붙이기 (3주차)
  • 이상한 요청 차단과 요청 횟수 제한

하고 싶은 기술

  • 스프링 시큐리티 로그인/로그아웃
  • 비밀번호 암호화 저장
  • SQL 인젝션·XSS 막기
  • HTTPS 인증서 적용
